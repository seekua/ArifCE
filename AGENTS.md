## README localization rule

When the content or section structure of the root `README.md` changes, apply the same change in the same work to every existing translated README under `docs/locales/`. Do not add or remove locale files unless explicitly requested. A README update is not complete until all translations, their section/content parity, and their links have been checked. For purely presentational changes that do not require translation, explain why in the change summary.
