# Failed Attempts

Rejected approaches are reusable engineering knowledge. Recording the approach, result, reason, task, and evidence can prevent a future session from repeating an expensive mistake.

```bash
arifce attempt record TASK-0001 "Redis Pub/Sub invalidation" --result rejected --reason "Reconnect reliability risk"
```

An attempt is not a permanent ban. New constraints or evidence may justify reconsideration, which should be recorded as a new decision rather than rewriting history.
