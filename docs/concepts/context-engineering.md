# Context Engineering

Context engineering selects the smallest useful projection of project intelligence for a task. The goal is not to preserve every token in every prompt; it is to preserve broadly and retrieve selectively.

The shared assembly path uses explainable lexical candidates, deterministic type priority, current trust state, stable ordering, and an explicit budget rather than silently dumping repository memory. Raw transcripts are excluded. `context explain` makes both selection and rejection inspectable.

This does not yet provide symbol-scoped freshness, conflict resolution, or proven task improvement. Effectiveness must be benchmarked using task correctness, irrelevant reads, latency, and context cost.
