# Codex

Codex should begin with `AGENTS.md`, `.arifce/PROTOCOL.md`, and `.arifce/CURRENT.md`, then use `arifce context` for the active task. It should not bulk-read `.arifce/raw/`.

Meaningful completion statements should become claims with deterministic evidence. Record decisions, rejected attempts, findings, checkpoints, and handoffs when they materially improve continuity.
