# Prior Art Scope

ArifCE overlaps with several established categories: ADRs preserve decisions, issue trackers preserve work, Git preserves source history, test systems provide deterministic evidence, search indexes retrieve text, and agent memory systems preserve conversational context.

Its product boundary is the combination: repository-owned continuity, claims linked to repository-scoped evidence, failed attempts, semantic handoffs, budgeted retrieval, and guarded refactor campaigns across agent vendors.

This is a research scope statement, not a comparative market claim. A sourced survey of specific tools is deferred until it can be maintained with dated primary references.
