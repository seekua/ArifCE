# V0.7 release checklist

Status: **published**. GitHub Release [`v0.7.0`](https://github.com/seekua/ArifCE/releases/tag/v0.7.0) is live. Platform binaries remain downloadable from the verified Actions artifact run while release asset upload stays maintainer-controlled.

## Before tagging

- [ ] Confirm the CLI, dashboard, and MCP version policy.
- [ ] Update the canonical version in project files and README examples.
- [ ] Run the full CI workflow on the release commit.
- [x] Create a signed or annotated `v0.7.0` tag.
- [x] Confirm the tag's release workflow produces all platform archives.
- [x] Verify each archive with `scripts/verify-release-artifacts.ps1`.
- [ ] Attach verified archives and checksums to the GitHub Release (manual artifact download/upload remains).
- [ ] Record the Actions run and release URLs in this checklist.

## Package-manager follow-up

After a stable release URL and checksums exist, submit manifests to Winget, Homebrew, and Scoop. Those submissions are external maintainer operations and must reference immutable release assets; placeholder manifests are intentionally not committed.
