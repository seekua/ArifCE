# V0.8 release checklist

Status: **release candidate**. This checklist is not a publication claim until the tag workflow and GitHub Release evidence below are complete.

## Scope

- Hardened evidence freshness, acceptance, canonical mutation, and secret-handling rules.
- Deterministic code graph and change impact contracts.
- Structured agent flight recorder and failed-attempt promotion.
- Strict MCP and verification command boundaries.
- Honest matched-task benchmark protocol.
- Five-platform self-contained CLI distribution with immutable release assets.

The CLI and npm launcher advance to `0.8.0`. MCP (`0.3.0`) and Dashboard (`0.5.0`) retain independent package versions because their public package contracts did not change in this release.

## Before tagging

- [x] Synchronize CLI, npm launcher, README, installation guide, and user guide versions.
- [x] Replace the unproven public NuGet installation claim with the verified self-contained distribution path.
- [x] Run version, secret, README parity, release-policy, package-smoke, and full behavior tests locally.
- [ ] Confirm the release commit passes the full remote CI matrix.
- [ ] Create and push the annotated `v0.8.0` tag from the verified release commit.

## Publication evidence

- [ ] Confirm all five native binaries execute successfully in the tag workflow.
- [ ] Confirm each binary archive passes its internal checksum.
- [ ] Confirm the release-level `SHA256SUMS` covers all five archives.
- [ ] Confirm GitHub Release `v0.8.0` contains exactly the five archives and `SHA256SUMS`.
- [ ] Record immutable workflow, release, tag, and commit links here.

## Explicitly deferred

- NuGet.org, npm registry, Winget, Homebrew, and Scoop publication require their respective maintainer credentials and are not claimed by this release.
- Binary signing and NativeAOT remain separate work; self-contained binaries remove the runtime-install requirement without claiming AOT.
