**让项目记住每一次代理变更。** ArifCE 是面向 AI 辅助开发团队的本地优先项目智能与连续性层。它把决策、证据、失败尝试和交接记录保存在代码仓库中。

## 快速开始

```powershell
dotnet tool install --global ArifCE.Cli
cd your-project
arifce init
arifce status
```

完整指南请参阅 [English documentation](docs/README.md)。
